## 0.1.0

Initial release.

- `PackageCollector` and `GrundGenerator.core()`: turn the DI annotations
  of a package (`@Module`, `@Injectable`, `@Provides`, `Bind`, `@Named`)
  into one `X.g.dart` per source library that declares modules, a
  `mixin $X on grund.Module` per module on the explicit API, with static
  validation of the module graph and diagnostics with a location and a
  code. The generator knows no HTTP; `@Api` is `grund_http_generator`'s.
- Deterministic, formatted output starting with the header
  `// GENERATED BY grund_generator. DO NOT EDIT.`; custom `Construct`s. A
  library and a part for one output path are a `conflicting_outputs`
  diagnostic.
- The emitters (`BindingEmitter`, `ConstantEmitter`, `TypeEmitter`,
  `DartString`, `CoreReferences`, `OverrideGetter`) are public for
  constructs of other packages; a `PartUnit` must belong to a source
  library of the package (`PackageModel.libraryPaths`) or to another
  generated file.
